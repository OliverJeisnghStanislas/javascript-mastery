# JavaScript Mastery — Complete JavaScript.info Language Track

This repository organizes the **The JavaScript language** track from [javascript.info](https://javascript.info/) into one parent folder, with a section folder for each chapter group and an individual folder for every article supplied in the learning plan.

## How to use this repository
For each article:
1. Read the linked tutorial.
2. Write a short explanation in that article's `README.md`.
3. Implement examples in `examples.js` without copy/paste first.
4. Solve the tasks in `exercises.js`.
5. Test edge cases and record mistakes.
6. Check off the completion items and commit your work.

## Suggested article folder contents
- `README.md` — concept notes, tutorial link, interview prompts, checklist
- `examples.js` — code examples you implement
- `exercises.js` — exercises to solve independently

## Repository-wide tracking
See [`PROGRESS.md`](./PROGRESS.md) for every section and article. Use Git commits to preserve progress.

## Running examples
Install Node.js from https://nodejs.org/ and run a file, for example:
```bash
node 02-javascript-fundamentals/01-hello-world/examples.js
```
Browser-specific topics (for example `alert`, `prompt`, `confirm`, and devtools) need a browser. Modules may require an appropriate HTML setup or Node.js module configuration.

## Learning advice
This is a scaffold, not a set of completed solutions. The value comes from writing and explaining the code yourself. Use the official tutorial links as the source of truth.
